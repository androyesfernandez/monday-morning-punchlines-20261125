This program writes a single original one-line joke about Monday mornings to `/output/entry.txt`. The joke's premise is a Monday standup where the boss asks for one win from the weekend, and the narrator's win is ignoring all forty-seven of the boss's emails — and the laugh lands in the last few words, when the boss nods and writes it down as a productivity tip instead of reprimanding him: the expected scolding flips into an endorsement.

## Run

```sh
node main.ts
```

Requires Node 22. No dependencies, no network access.
